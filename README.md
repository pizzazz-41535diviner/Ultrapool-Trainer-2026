## 🎮 About the Game

Ultrapool is a colorful single-player roguelike pool game developed by Icedrop Games and published by offbrand games. It was released on August 24, 2026, and combines billiards, strategy, deckbuilding, and arcade physics.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Ultrapool**. This trainer enhances Ultrapool runs by modifying score, bar currency, round progression, and shot-related resources. It is designed around the game's core loop of pocketing balls, building a collection of effect-driven balls, purchasing upgrades, and surviving ten rounds.

**Target Audience:** Players who want to experiment with unusual ball combinations, test score strategies, explore higher difficulty modes, practice trickshots, or reduce the repetition of failed roguelike runs.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Ultrapool is played from a fixed pool-table view rather than through free character movement. Use the mouse or supported input controls to aim the cue, adjust shot strength, and select the intended direction. Shot Assistance can help with controlled practice and difficult trickshots.

### Tools & Inventory

The main inventory is the player's collection and active set of balls. Balls have different effects and can be purchased or improved with money earned from score. Use Infinite Bar Currency to test upgrades, combine complementary effects, and experiment with different builds without normal spending limits.

### World & Environment

Runs take place across a sequence of pool rounds. Pocketing balls generates score, and score produces money for purchases at the bar. A standard run requires surviving ten rounds, while difficulty modes, ball sets, snacks, and negative-effect cubes add further strategic variation.

### Combat & Weapons

Ultrapool has no conventional combat system. The Combat category refers to shot execution and table interaction. Use Shot Assistance for practice, and use score and round options to focus on how ball abilities interact with pockets, collisions, trickshots, and other table events.
